# Information-Theoretic Diffusion 복습 노트

> 확률을 계산하는 일과 잡음을 지우는 일은 사실 같은 문제라는 것을 수학적으로 증명한 논문입니다.

| 항목 | 내용 |
| --- | --- |
| 제목 | Information-Theoretic Diffusion |
| 저자 | Xianghao Kong, Rob Brekelmans, Greg Ver Steeg |
| 발표 | ICLR 2023 |
| 링크 | [arXiv:2302.03792](https://arxiv.org/abs/2302.03792) |
| 대상 | 확산 모델(이미지 생성 인공지능) |
| 방법 | 정보 이론, 확률통계, 미적분 |

대상은 인공지능이고 다루는 방법은 수학인 이론 논문입니다. 그림을 만드는 법이 아니라, 같은 잡음 제거 능력으로 확률을 계산하는 법을 다룹니다.

---

## 1장: 확산 모델의 기본 원리

확산 모델은 사진에 잡음을 섞었다가, 신경망이 그 잡음을 한 단계씩 지우도록 학습시킨 생성 인공지능입니다. Stable Diffusion, NovelAI 이미지 생성기가 이 계열입니다.

- **초반**: 잡음만 가득, 거의 아무것도 정해지지 않음
- **중반**: 형체가 확 잡힘, 구도와 색 배치 같은 큰 정보가 결정됨
- **후반**: 세부만 다듬음

**논문의 질문**: 모델이 데이터를 얼마나 잘 이해하는지 재려면 확률 p(x)를 구해야 합니다. 기존에는 근사치(변분 하한)만 계산했습니다. 이 논문은 정확한 등식을 제시합니다.

## 정보 이론 기초

| 개념 | 한 줄 뜻 | 예시 |
| --- | --- | --- |
| 정보량 −log p(x) | 드문 일일수록 놀라움이 큼 | 7월에 눈이 오면 정보량이 큼 |
| 엔트로피 H | 평균 놀라움 = 보기 전에 얼마나 모르는가 | 공정한 동전은 1비트, 앞면만 나오는 동전은 0 |
| 상호정보량 I(X; Y) | Y를 보고 나서 줄어든 X의 막막함 | 초성 힌트로 답 후보가 줄어든 만큼 |
| KL 발산 | 틀린 가설을 믿어서 평균적으로 더 겪는 충격 | 공정한 동전을 앞면 90%로 믿을 때 |

$$
I(X;Y) = H(X) - H(X \mid Y)
$$

KL 발산은 항상 0 이상이며, 두 분포가 같으면 0입니다.

## 2장: I-MMSE 관계

선명도를 조금 올리면 새로 얻는 정보의 양은, 지금 최선을 다해도 남는 잡음 제거 오차의 절반입니다.

$$
\frac{d}{d\gamma} I(x; z_\gamma) = \frac{1}{2}\,\mathrm{mmse}(\gamma)
$$

- γ: 신호대잡음비(SNR), 즉 선명도
- z_γ: 잡음 섞인 이미지, x: 원본 이미지
- mmse: 최적의 잡음 제거기가 내는 평균제곱오차

논리 명제(A이면 B)가 아니라 두 양이 값으로 같다는 등식입니다. 반비례 관계도 아니며, 아직 모르는 만큼 새로 배울 여지가 있다는 뜻입니다.

**점별 일반화(식 4)**: 저자들은 이 공식을 사진 한 장 단위로 쪼갰습니다.

$$
\frac{d}{d\gamma} D_{KL}[\,p(z_\gamma \mid x) \,\|\, p(z_\gamma)\,] = \frac{1}{2}\,\mathrm{mmse}(x, \gamma)
$$

왼쪽은 "잡음 속에서 이 사진이 다른 사진들과 얼마나 구별되는가"입니다. 모든 사진에 대해 평균 내면 식 (1)로 돌아갑니다.

## 3장: 적분으로 확률 구하기

순간의 변화 속도(식 4)를 처음부터 끝까지 쌓으면(적분) 확률이 정확하게 나옵니다. 사용한 도구는 미적분의 기본정리입니다.

**식 (6)의 문제**: 확률 = 사전 손실 + 재구성 손실 − 확산 손실 꼴이 나오지만, 적분 범위를 0부터 무한대로 넓히면 항들이 각각 무한대로 발산합니다.

**식 (9)의 해결**: 정규분포를 기준선(해수면)으로 세우고 차이만 잽니다.

$$
-\log p(x) = \frac{d}{2}\log(2\pi e) - \frac{1}{2}\int_0^\infty \left( \frac{d}{1+\gamma} - \mathrm{mmse}(x, \gamma) \right) d\gamma
$$

- d: 차원 수(픽셀 값의 개수)
- d/(1+γ): 데이터가 정규분포였다면 나왔을 오차(기준선)
- 괄호 안 차이: 실제 데이터가 정규분포보다 얼마나 더 잘 지워지는가

정규분포는 같은 분산을 가진 분포 중 잡음을 지우기 가장 어려운 분포(아무 단어나 정답일 수 있는 초성 문제)라서, 이 차이는 이론상 항상 0 이상입니다. 패턴이 뚜렷할수록 그만큼을 빼게 되어 확률이 높게 나옵니다.

**이산 데이터(식 12)**: 픽셀처럼 딱딱 떨어지는 값은 기준선 없이도 성립합니다.

$$
-\log P(x) = \frac{1}{2}\int_0^\infty \mathrm{mmse}(x, \gamma)\, d\gamma
$$

## 4장: 실제로 계산하기

| 문제 | 해결책 |
| --- | --- |
| 신경망은 최적이 아니다 | 계산값을 상한(이 정도보다는 낫다는 보증)으로 쓴다. 정규분포보다 못한 구간은 정규분포용 공식으로 대체한다 |
| 0부터 무한대까지 적분을 정확히 못 한다 | 몇몇 지점을 뽑아 평균을 낸다(몬테카를로). 연속 데이터는 약 100개 지점이면 충분하다 |

$$
\text{(신경망의 오차)} = \mathrm{mmse} + \text{(실력 부족분)} \geq \mathrm{mmse}
$$

- **잡음 예측**: 신경망은 원본 대신 섞인 잡음 ε을 맞힌다. 잡음을 알면 빼서 원본을 구할 수 있어 같은 문제다.
- **로그 선명도**: γ 대신 α = log γ를 쓴다. 범위가 너무 넓어서다.
- **중요도 표본추출**: 정보가 몰리는 중간 구간을 더 많이 뽑고 가중치로 보정한다. 뽑는 분포는 로지스틱 분포다.
- **이산 데이터**: 양 끝 구간은 계산하지 않고 최대값만 묶어 둔다. 아주 선명할 때는 반올림만 해도 거의 다 맞는다.

## 5장: 실험 결과 (표 1, 표 2)

실험은 CIFAR-10(32×32 컬러 사진, 픽셀 값을 −1~1로 조정)에서, 이미 학습된 DDPM과 IDDPM을 가져와 진행했습니다.

**점수의 단위, bpd(차원당 비트)**: 사진 한 장을 압축할 때 픽셀 값 하나에 평균 몇 비트가 필요한지를 나타냅니다. −log p(x)를 픽셀 값 개수(3,072개)로 나눈 값입니다. 데이터를 잘 이해한 모델은 덜 놀라므로 **낮을수록 좋습니다.**

**표 1: 연속 확률밀도 (bpd, 시험 데이터)**

| 모델 | 기존(변분) | 이 논문(IT) |
| --- | --- | --- |
| DDPM | −3.44 | −3.56 |
| IDDPM | −3.58 | −4.09 |
| DDPM 미세조정 | −3.51 | −3.84 |
| IDDPM 미세조정 | −3.55 | −4.28 |
| 앙상블 | − | −4.29 |

- 확률은 1을 넘지 못하지만 확률밀도는 1을 넘을 수 있습니다(좁은 방의 인구밀도). 픽셀 값을 좁은 구간에 몰아 두었으므로 밀도가 커지고 −log 값은 음수가 됩니다.
- 음수여도 **낮을수록 좋습니다**(골프 4언더파가 3언더파보다 좋은 것과 같습니다). 절댓값이 작은 쪽이 좋은 것이 아닙니다.
- 같은 신경망을 그대로 쓰고 계산 방식만 바꿨는데 점수가 좋아졌습니다. IDDPM은 분산을 예측하는 부분을 버리고도 더 좋았습니다. "잡음 제거 오차만 있으면 충분하다"는 주장의 근거입니다.
- 잡음 제거 오차로 미세조정하면 주로 선명한 구간의 오차가 줄어 점수가 더 좋아집니다.

**표 2: 이산 확률 (bpd, 시험 데이터)**

| 모델 | 기존(변분) | 이 논문(IT) |
| --- | --- | --- |
| DDPM | 3.37 | 3.68 |
| IDDPM | 2.94 | 3.16 |
| DDPM 미세조정 | 3.45 | 3.48 |
| IDDPM 미세조정 | 3.14 | 3.15 |
| 앙상블 | − | 2.90 |

- 모델을 하나씩 비교하면 이 논문의 방식이 오히려 나쁩니다. 이산 공식은 "아주 선명하면 반올림만 해도 다 맞는다"는 성질에 기대는데, 기존 신경망은 예측을 정수 칸에 딱 맞추지 못합니다.
- 그래서 **부드러운 반올림**을 덧붙였습니다(부록 B.4).
  - 딱딱한 반올림은 가까운 눈금 하나로 확 자르므로 경계 근처에서 한 칸 통째로 틀릴 수 있습니다. 실제로 오차가 커졌습니다.
  - 부드러운 반올림은 가까운 눈금들의 가중평균입니다. 가까울수록 가중치가 큽니다.
  - 선명도가 온도 조절기 역할을 합니다. 선명하면 거의 딱딱한 반올림이 되고, 흐리면 거의 손대지 않습니다.
  - 미분할 수 있어서 학습에 쓰기 좋습니다. 다만 흐린 구간에서는 오차를 키웁니다.

**앙상블**: 식 (9)와 (12)는 선명도마다 가장 작은 오차 하나만 요구합니다. 그러니 구간마다 가장 잘하는 모델을 골라 써도 공식이 그대로 성립합니다. 반올림 모델은 선명한 구간만 맡깁니다. 이렇게 합친 앙상블(2.90)이 모든 단일 모델을 이겼습니다.

**주인님의 질문: 앙상블은 무조건 더 좋습니까?**
1. 나빠지지는 않습니다. 선명도마다 최솟값을 고르므로, 앙상블의 오차 곡선은 어떤 단일 모델보다도 위로 갈 수 없습니다.
2. 얼마나 좋아지는지는 곡선이 얼마나 엇갈리는가에 달려 있으며, 정해진 기준치는 없습니다. 이득은 "가장 좋은 단일 모델보다 다른 모델이 더 잘하는 구간의 넓이 × ½"입니다. 한 모델이 모든 구간에서 1등이면 이득은 0입니다.
3. 선명도는 데이터의 성질이 아니라 모든 사진에 대해 훑는 변수입니다. 데이터에 따라 달라지는 것은 어느 구간에서 어느 모델이 강한가입니다. 두 값뿐인 흑백 그림처럼 이산성이 강한 데이터라면 반올림 모델의 이득이 클 것이라는 짐작이 가능하지만, 논문에서 실험한 내용은 아닙니다.
4. 논문은 시험 데이터에서 직접 모델을 골랐으므로 조금 낙관적일 수 있습니다. 저자들도 검증용 데이터로 고르는 편이 낫다고 적었습니다. 또한 이산 추정값은 흔들림이 큽니다(부록 표 5, 표본 100개 기준 표준편차 약 0.27).

## 비유와 한자 풀이

| 개념 | 비유 |
| --- | --- |
| I-MMSE 관계 | 초성 퀴즈: 빈칸일 때 힌트 하나는 효과가 크고, 거의 맞힌 뒤의 힌트는 효과가 작다 |
| KL 발산 | 공정한 동전을 앞면 90%라고 믿을 때 더 겪는 충격 |
| 정규분포 기준선 | 산 높이를 지구 중심 대신 해수면부터 재기 |
| 신경망이 약한 구간 대체 | 공부 안 한 과목은 찍는 게 낫다 |
| 몬테카를로 | 여론조사처럼 표본으로 전체를 추정 |
| 확률밀도가 1을 넘음 | 좁은 방에 사람이 몰리면 인구밀도가 커진다 |
| bpd 비교 | 골프 점수: 낮을수록 좋고, 4언더파(−4)가 3언더파(−3)보다 좋다 |
| 계산값이 상한인 이유 | 택시가 돌아서 가면 요금은 최단 경로보다 항상 많이 나온다 |
| 부드러운 반올림 | 저울 바늘이 눈금 사이에 있으면 확 자르지 않고 그 사이 값을 읽는다 |
| 앙상블 | 퀴즈 대회 팀전: 과목마다 가장 잘하는 사람이 답한다 |

- **미분(微分)**: 작을 미 + 나눌 분. 아주 작게 나눠 그 순간의 변화 속도를 본다.
- **적분(積分)**: 쌓을 적 + 나눌 분. 잘게 나눈 것을 쌓아 올린다.

### 5장 퀴즈 (2026-10-21)

<details>
<summary>복습. 신경망으로 계산한 −log p(x)는 정확한 값입니까, 상한입니까, 하한입니까?</summary>

상한입니다. 신경망의 오차는 언제나 최적의 오차보다 크거나 같으므로, 그 오차를 쌓은 값도 진짜 값보다 크거나 같습니다(택시 요금 비유). 식 (12)에 기준선이 필요 없다는 것과는 다른 이야기입니다.
</details>

<details>
<summary>10. bpd는 높을수록 좋습니까, 낮을수록 좋습니까?</summary>

낮을수록 좋습니다. 데이터를 잘 이해한 모델은 덜 놀라므로 정보량이 작습니다.
</details>

<details>
<summary>11. 표 1에서 −log p(x)가 음수로 나올 수 있는 이유는?</summary>

확률이 아니라 확률밀도이기 때문입니다. 좁은 구간(−1~1)에 값이 몰리면 밀도가 1보다 커지고, −log 값은 음수가 됩니다. 이때도 낮을수록 좋습니다.
</details>

<details>
<summary>12. 표 2에서 모델을 하나씩 비교하면 어느 방식이 더 좋습니까? 이유는?</summary>

기존(변분) 방식입니다. 이산 공식은 선명할 때 반올림만 해도 맞는 성질에 기대는데, 기존 신경망이 정수 칸에 예측을 맞추지 못하기 때문입니다.
</details>

<details>
<summary>13. 앙상블이 이 논문의 공식과 특히 잘 맞는 이유는?</summary>

공식이 선명도마다 가장 작은 오차 하나만 요구하므로, 구간마다 다른 모델을 골라 써도 공식이 그대로 성립하기 때문입니다.
</details>

<details>
<summary>14. 모델 A는 흐릴 때, 모델 B는 선명할 때 오차가 작습니다. 앙상블은 단일 모델보다 어떻게 됩니까?</summary>

좋아집니다. 적어도 나빠지지는 않으며, 서로 이기는 구간이 엇갈리는 만큼 좋아집니다.
</details>

<details>
<summary>확인 문제 1. 모델 X는 −3.9 bpd, 모델 Y는 −4.2 bpd입니다. 어느 쪽이 더 좋습니까?</summary>

Y입니다. −4.2가 더 낮습니다(4.2언더파).
</details>

<details>
<summary>확인 문제 2. 신경망으로 계산한 값이 3.2 bpd였습니다. 진짜 −log P(x)가 3.2보다 클 수 있습니까?</summary>

없습니다. 계산값은 상한이므로 진짜 값은 3.2 이하입니다.
</details>

### 주인님의 정리: 택시 요금으로 보는 상한

집에서 학교까지 최단 거리로 가면 5,000원입니다. 그런데 기사가 빙빙 돌아서 가면 7,000원이 나옵니다. 실제로 낸 돈은 7,000원입니다.

이 7,000원을 보고 말할 수 있는 것은 "최단 요금은 7,000원보다 많을 수 없다"입니다.

$$
\text{진짜 최단 요금} \leq 7{,}000\text{원}
$$

신경망도 똑같습니다. 신경망이 계산한 오차(또는 −log p(x))는 최적의 모델이 낼 수 있는 오차보다 항상 크거나 같습니다. 그래서 신경망이 3.2라고 계산했다면, 진짜 −log P(x)는 3.2보다 클 수 없습니다. 진짜 값은 3.2 이하이며, 3.2는 상한입니다.
