# Information-Theoretic Diffusion 복습 노트

> 확률을 계산하는 일과 잡음을 지우는 일은 사실 같은 문제라는 것을 수학적으로 증명한 논문입니다.

| 항목 | 내용 |
| --- | --- |
| 제목 | Information-Theoretic Diffusion |
| 저자 | Xianghao Kong, Rob Brekelmans, Greg Ver Steeg |
| 발표 | ICLR 2023 |
| 링크 | [arXiv:2302.03792](https://arxiv.org/abs/2302.03792) |
| 대상 | 확산 모델(이미지 생성 인공지능) |
| 방법 | 정보 이론, 확률통계, 미적분 |

대상은 인공지능이고 다루는 방법은 수학인 이론 논문입니다. 그림을 만드는 법이 아니라, 같은 잡음 제거 능력으로 확률을 계산하는 법을 다룹니다.

---

## 1장: 확산 모델의 기본 원리

확산 모델은 사진에 잡음을 섞었다가, 신경망이 그 잡음을 한 단계씩 지우도록 학습시킨 생성 인공지능입니다. Stable Diffusion, NovelAI 이미지 생성기가 이 계열입니다.

- **초반**: 잡음만 가득, 거의 아무것도 정해지지 않음
- **중반**: 형체가 확 잡힘, 구도와 색 배치 같은 큰 정보가 결정됨
- **후반**: 세부만 다듬음

**논문의 질문**: 모델이 데이터를 얼마나 잘 이해하는지 재려면 확률 p(x)를 구해야 합니다. 기존에는 근사치(변분 하한)만 계산했습니다. 이 논문은 정확한 등식을 제시합니다.

---

## 정보 이론 기초

| 개념 | 한 줄 뜻 | 예시 |
| --- | --- | --- |
| 정보량 −log p(x) | 드문 일일수록 놀라움이 큼 | 7월에 눈이 오면 정보량이 큼 |
| 엔트로피 H | 평균 놀라움 = 보기 전에 얼마나 모르는가 | 공정한 동전은 1비트, 앞면만 나오는 동전은 0 |
| 상호정보량 I(X; Y) | Y를 보고 나서 줄어든 X의 막막함 | 초성 힌트로 답 후보가 줄어든 만큼 |
| KL 발산 | 틀린 가설을 믿어서 평균적으로 더 겪는 충격 | 공정한 동전을 앞면 90%로 믿을 때 |

$$
I(X;Y) = H(X) - H(X \mid Y)
$$

KL 발산은 항상 0 이상이며, 두 분포가 같으면 0입니다.

## 2장: I-MMSE 관계

선명도를 조금 올리면 새로 얻는 정보의 양은, 지금 최선을 다해도 남는 잡음 제거 오차의 절반입니다.

$$
\frac{d}{d\gamma} I(x; z_\gamma) = \frac{1}{2}\,\mathrm{mmse}(\gamma)
$$

- γ: 신호대잡음비(SNR), 즉 선명도
- z_γ: 잡음 섞인 이미지, x: 원본 이미지
- mmse: 최적의 잡음 제거기가 내는 평균제곱오차

논리 명제(A이면 B)가 아니라 두 양이 값으로 같다는 등식입니다. 반비례 관계도 아니며, 아직 모르는 만큼 새로 배울 여지가 있다는 뜻입니다.

**점별 일반화(식 4)**: 저자들은 이 공식을 사진 한 장 단위로 쪼갰습니다.

$$
\frac{d}{d\gamma} D_{KL}[\,p(z_\gamma \mid x) \,\|\, p(z_\gamma)\,] = \frac{1}{2}\,\mathrm{mmse}(x, \gamma)
$$

왼쪽은 "잡음 속에서 이 사진이 다른 사진들과 얼마나 구별되는가"입니다. 모든 사진에 대해 평균 내면 식 (1)로 돌아갑니다.

## 3장: 적분으로 확률 구하기

순간의 변화 속도(식 4)를 처음부터 끝까지 쌓으면(적분) 확률이 정확하게 나옵니다. 사용한 도구는 미적분의 기본정리입니다.

**식 (6)의 문제**: 확률 = 사전 손실 + 재구성 손실 − 확산 손실 꼴이 나오지만, 적분 범위를 0부터 무한대로 넓히면 항들이 각각 무한대로 발산합니다.

**식 (9)의 해결**: 정규분포를 기준선(해수면)으로 세우고 차이만 잽니다.

$$
-\log p(x) = \frac{d}{2}\log(2\pi e) - \frac{1}{2}\int_0^\infty \left( \frac{d}{1+\gamma} - \mathrm{mmse}(x, \gamma) \right) d\gamma
$$

- d: 차원 수(픽셀 값의 개수)
- d/(1+γ): 데이터가 정규분포였다면 나왔을 오차(기준선)
- 괄호 안 차이: 실제 데이터가 정규분포보다 얼마나 더 잘 지워지는가

정규분포는 같은 분산을 가진 분포 중 잡음을 지우기 가장 어려운 분포(아무 단어나 정답일 수 있는 초성 문제)라서, 이 차이는 이론상 항상 0 이상입니다. 패턴이 뚜렷할수록 그만큼을 빼게 되어 확률이 높게 나옵니다.

**이산 데이터(식 12)**: 픽셀처럼 딱딱 떨어지는 값은 기준선 없이도 성립합니다.

$$
-\log P(x) = \frac{1}{2}\int_0^\infty \mathrm{mmse}(x, \gamma)\, d\gamma
$$

## 4장: 실제로 계산하기

| 문제 | 해결책 |
| --- | --- |
| 신경망은 최적이 아니다 | 계산값을 상한(이 정도보다는 낫다는 보증)으로 쓴다. 정규분포보다 못한 구간은 정규분포용 공식으로 대체한다 |
| 0부터 무한대까지 적분을 정확히 못 한다 | 몇몇 지점을 뽑아 평균을 낸다(몬테카를로). 연속 데이터는 약 100개 지점이면 충분하다 |

$$
\text{(신경망의 오차)} = \mathrm{mmse} + \text{(실력 부족분)} \geq \mathrm{mmse}
$$

- **잡음 예측**: 신경망은 원본 대신 섞인 잡음 ε을 맞힌다. 잡음을 알면 빼서 원본을 구할 수 있어 같은 문제다.
- **로그 선명도**: γ 대신 α = log γ를 쓴다. 범위가 너무 넓어서다.
- **중요도 표본추출**: 정보가 몰리는 중간 구간을 더 많이 뽑고 가중치로 보정한다. 뽑는 분포는 로지스틱 분포다.
- **이산 데이터**: 양 끝 구간은 계산하지 않고 최대값만 묶어 둔다. 아주 선명할 때는 반올림만 해도 거의 다 맞는다.

## 비유와 한자 풀이

| 개념 | 비유 |
| --- | --- |
| I-MMSE 관계 | 초성 퀴즈: 빈칸일 때 힌트 하나는 효과가 크고, 거의 맞힌 뒤의 힌트는 효과가 작다 |
| KL 발산 | 공정한 동전을 앞면 90%라고 믿을 때 더 겪는 충격 |
| 정규분포 기준선 | 산 높이를 지구 중심 대신 해수면부터 재기 |
| 신경망이 약한 구간 대체 | 공부 안 한 과목은 찍는 게 낫다 |
| 몬테카를로 | 여론조사처럼 표본으로 전체를 추정 |

- **미분(微分)**: 작을 미 + 나눌 분. 아주 작게 나눠 그 순간의 변화 속도를 본다.
- **적분(積分)**: 쌓을 적 + 나눌 분. 잘게 나눈 것을 쌓아 올린다.

## 챕터별 퀴즈

<details>
<summary>1. 이미지 생성 과정에서 형체가 "확" 잡히는 구간은 초반, 중반, 후반 중 언제입니까?</summary>

중반입니다. 초반은 아직 막막하고, 후반은 이미 거의 정해져서 새로 얻는 정보가 적습니다.
</details>

<details>
<summary>2. 공정한 동전과 앞면만 나오는 동전 중 엔트로피가 더 높은 쪽은?</summary>

공정한 동전입니다. 엔트로피는 예측 불가능성입니다.
</details>

<details>
<summary>3. KL 발산이 0이라면 두 분포는 어떤 관계입니까?</summary>

두 분포가 같습니다. KL 발산은 항상 0 이상입니다.
</details>

<details>
<summary>4. "선명도를 조금 올릴 때 새로 얻는 정보 = 잡음 제거 오차의 ( )"</summary>

절반입니다.
</details>

<details>
<summary>5. 이 관계는 논리 명제입니까, 등식입니까?</summary>

등식입니다.
</details>

<details>
<summary>6. 식 (9)에서 기준선 역할을 하는 분포는?</summary>

정규분포(가우시안)입니다. 4장의 "신경망의 실력 부족분"과 헷갈리지 않도록 주의합니다. 기준선은 계산을 가능하게 하는 해수면이고, 실력 부족분은 현실에서 계산할 때 생기는 추가 오차입니다.
</details>

<details>
<summary>7. 적분의 '적(積)'은 무슨 뜻입니까?</summary>

쌓을 적입니다. 미분과 반대입니다.
</details>

<details>
<summary>8. 신경망은 원본 이미지 대신 무엇을 맞히도록 학습합니까?</summary>

섞인 잡음 ε입니다.
</details>

<details>
<summary>9. 적분을 계산할 때 중간 구간을 더 많이 뽑는 방법의 이름은?</summary>

중요도 표본추출입니다.
</details>

<details>
<summary>확인 문제. 식 (9)의 괄호 안 값 "d/(1+γ) − mmse(x, γ)"는 무엇을 뜻합니까?</summary>

실제 데이터가 정규분포보다 얼마나 더 잘 지워지는가입니다. 이 값은 항상 0 이상이고, 모든 선명도에 걸쳐 쌓으면 데이터의 패턴, 곧 확률 정보가 됩니다.
</details>
